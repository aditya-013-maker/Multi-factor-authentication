# Steel Corp Portal (Demo Login Project)

A responsive two-page login demo built with plain HTML, CSS, and JavaScript —
works on desktop (Windows/Mac) and mobile (Android/iOS) through any browser.

## Features
- Company logo placeholder at the top of the login page
- Employee Personal ID + Password fields
- Auto-generated captcha with refresh option
- Password rule hint: must include lowercase, uppercase, a special character,
  and be at least 8 characters long
- On correct ID + password + captcha → moves to a second page with an
  "I'm not a robot" confirmation checkbox
- On success → displays "You have successfully logged in"
- On incorrect ID, password, or captcha → displays
  "You have entered a wrong ID no. or password or captcha"
